# Jobora – Job Board Website

Jobora is a modern, responsive job portal built with React, Vite, and Tailwind CSS. It helps users explore job opportunities, search by title or location, discover companies, save jobs, and manage their job-search activity through a simple dashboard.

## Features

- **Modern Home Page** – Hero section, job search, featured opportunities, categories, and company listings.
- **Job Listings** – Browse job openings with search, filters, and sorting.
- **Job Details** – View job descriptions, responsibilities, required skills, salary, and experience.
- **Search Functionality** – Search for jobs by keyword and location.
- **Company Logos** – Display company logos in job cards and company sections.
- **Save Jobs** – Bookmark interesting jobs and access them later.
- **Authentication UI** – Sign-in and sign-up pages with form validation and password visibility toggle.
- **Dashboard** – View saved jobs and application information.
- **Responsive Design** – Optimized for desktop, tablet, and mobile screens.
- **Smooth Scrolling** – Smooth page navigation and scrolling.
- **Interactive UI** – Hover effects, transitions, icons, and responsive navigation.
- **Local Storage** – Persist selected demo data between browser sessions.

## Tech Stack

- React
- Vite
- Tailwind CSS
- JavaScript (ES6+)
- React Router DOM
- Lucide React
